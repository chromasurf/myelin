◆ COG_USERSCRIPTS scripts – theme – origin –

Every script here is an example — copy it into your application with mix cog_userscripts.copy <name> and adapt it. The glyph and the name switch one on or off, and every option on a card sets a <meta> tag. All of it reloads the page: these values are read once, when a script is injected, so there is nothing to switch at runtime.

This origin is not trusted, so no meta tag counts — every option on every card below is inert until you switch the origin back under Configuration. Only test/config.json is left, which is exactly the foreign-page case.

theme is one key five scripts share, which is why it is here and not five times over. origin is what a device works out from the page against trusted_origins; switched off you get the foreign page — no meta tag has any effect, including a page that tries to switch a script off by claiming cog-disable.

What runtime.exs holds on a real kiosk. Edit the file and reload — the harness re-reads it per request. Only what a device would genuinely set is here: everything except keyboard and screensaver carries "enabled": false in its own manifest, so this file switches on the two the harness needs to be useful — a bar to look at and fields to type into — and off what would collide in one page: a second bar claiming the top edge, a lock over everything. The PIN is deliberately a number, which is how it arrives from runtime.exs.
